# 🗒️ Task Manager

## Simple, yet powerful task manager. Manage your to-do list with ease!

### ✅ Main Features
1. Task Creation: With few taps you can create your first task.
2. Task Editing: You misspelled something? editing your task is as simple as tapping few buttons.
3. Task Delete: Want to delete your task?
4. Task Checking: You completed your task with success? give it a good check!
5. Filtering: Simply use the available filters to see your Done tasks and your to-dos. 
6. Persistence: All data is constantly saved in your localStorage
7. Themes: Both Light and Dark theme are available to use
8. Mobile view: Are you a mobile user? no fear,
